# Family Hub App 👨‍👩‍👧‍👦

A comprehensive family management application to help families stay connected and organized.

## Features

### 📊 Overview Dashboard
- Real-time statistics showing family members, events, tasks, and notes
- Recent activity feed to keep track of all family updates
- Clean, modern interface with gradient design

### 👥 Family Members
- Add and manage family member profiles
- Assign roles (Parent, Child, Grandparent, Other)
- Customize with emoji avatars
- Beautiful card-based display

### 📅 Events Calendar
- Create and track family events
- Add event descriptions and dates
- Chronologically sorted display
- Perfect for birthdays, holidays, and special occasions

### ✅ Tasks & Chores
- Create tasks and assign to family members
- Track completion status with checkboxes
- Filter between active and completed tasks
- Great for household chores and responsibilities

### 📝 Shared Notes
- Family bulletin board for important notes
- Sticky note design for visibility
- Author attribution and timestamps
- Keep everyone informed

### 📸 Photo Gallery
- Store family memories
- Add captions to photos
- Grid-based photo display
- Placeholder system with emojis

## Technology Stack

- **Pure HTML/CSS/JavaScript** - No frameworks required
- **LocalStorage** - Data persists in browser
- **Responsive Design** - Works on mobile and desktop
- **Modern UI** - Gradient themes and smooth animations

## How to Use

1. Open `family-app.html` in any modern web browser
2. Start by adding family members in the Members tab
3. Create events, tasks, and notes as needed
4. All data is automatically saved to your browser's local storage
5. Navigate between sections using the top navigation tabs

## Features Breakdown

### Adding Members
1. Click "Members" tab
2. Click "Add Member" button
3. Enter name, select role, and choose an emoji avatar
4. Member appears in the grid view

### Creating Events
1. Click "Events" tab
2. Click "Add Event" button
3. Fill in title, date, and description
4. Events are automatically sorted by date

### Managing Tasks
1. Click "Tasks" tab
2. Click "Add Task" button
3. Enter task title and assign to a family member
4. Check off tasks when completed

### Writing Notes
1. Click "Notes" tab
2. Click "Add Note" button
3. Select author and write your note
4. Notes appear in reverse chronological order

### Adding Photos
1. Click "Photos" tab
2. Click "Add Photo" button
3. Choose an emoji icon and optional caption
4. Photos display in a responsive grid

## Data Persistence

All data is stored locally in your browser using localStorage. This means:
- ✅ No server required
- ✅ Works offline
- ✅ Data persists between sessions
- ⚠️ Data is browser-specific (not synced across devices)
- ⚠️ Clearing browser data will delete all family information
